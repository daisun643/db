# 开发指南

## 1. 环境要求

- Docker Engine 与 Docker Compose 插件；
- Git；
- `uv`（运行 Python API 测试）；
- 可选：.NET 8 SDK、Node.js 20+，用于脱离容器开发。

默认端口：前端 `5173`、API `8080`、Oracle 主机端口 `1522`、MinIO `9000/9001`。启动前确认端口未被占用。

## 2. 启动与停止

```bash
# 构建、启动并等待服务健康；默认保留数据
./scripts/restart.sh --wait

# 不重建镜像
./scripts/restart.sh --no-build --wait

# 查看状态和日志
docker compose ps
docker compose logs -f backend-api

# 停止服务，保留数据卷
docker compose down --remove-orphans
```

只有需要从头执行 Oracle 初始化脚本时才删除数据卷：

```bash
./scripts/restart.sh --reset-data --wait
```

`--reset-data` 会删除 Oracle、MinIO 和前端依赖卷，数据不可恢复，不得用于生产环境。

启动后访问：

- 前端：`http://localhost:5173`
- Swagger：`http://localhost:8080/swagger`
- 健康检查：`http://localhost:8080/api/health`
- MinIO 控制台：`http://localhost:9001`

## 3. 目录结构

```text

  Data/AppDbContext.cs    EF Core 映射

  src/views/              页面
```

## 4. 配置

Compose 开发环境通过环境变量配置后端：

| 配置 | 用途 |
| --- | --- |
| `ConnectionStrings__Oracle` | Oracle 连接字符串 |
| `MediaStorage__Provider` | 媒体存储提供方，开发环境为 `s3` |
| `MediaStorage__S3__Endpoint` | MinIO/S3 地址 |
| `MediaStorage__S3__Bucket` | 媒体 Bucket |
| `MediaStorage__S3__AccessKey` / `SecretKey` | 存储凭据 |
| `VITE_API_BASE_URL` | 前端 API 地址 |

仓库中的 Compose 凭据仅用于本地开发。生产环境必须通过安全的环境配置或密钥服务注入，不得提交真实密钥和 `.env`。
ASP.NET 数据保护密钥由 `backend_data_protection` 卷持久化；多实例生产部署必须改用所有后端实例共享且静态加密的密钥存储。

## 5. 数据库开发

Oracle 初始化脚本位于 `database/`，按文件名前缀顺序在数据卷首次创建时执行。
各阶段职责、媒体数据约定和维护规则见 `database/README.md`。
触发器、存储过程和视图的职责与错误码见 `docs/数据库触发器与存储过程.md`。

开发约定：

- 新表、字段和索引应提供可审查的 SQL；
- 已执行过的脚本不会因容器重启自动重跑；
- 已部署环境优先新增幂等迁移脚本，不依赖修改旧脚本；
- EF Core 实体、`AppDbContext` 映射、SQL 列名和 DTO 必须同步；
- 派生字段与跨表不变式优先写成触发器或存储过程，不在多个控制器里重复实现；
- 存储过程不自行 `COMMIT`，事务边界由调用方控制；失败时通过 `p_code` 与 `p_message` 回传；
- 修改 PL/SQL 对象后需重建数据卷或以 `appuser` 重跑对应脚本，并同步更新脚本末尾的校验阈值；
- 用 `--reset-data` 验证全量初始化前，确认不需要保留本地数据。

## 6. 后端开发

新增或修改接口时：

1. 在 DTO 上设置必填、长度和数值范围；
2. 使用 `[Authorize]`、Permission Claim 和资源所有权做服务端授权；
3. 复用 `ICreditService`、`INotificationService`、`IMediaStorageService`；
4. 涉及库存、钱包、订单或退款时调用 `database/09_procedures.sql` 的存储过程，不在控制器里重写状态机；
5. 存储过程统一通过 `OracleProcedure.CallAsync` 调用，失败时把 `p_message` 作为错误提示返回；
6. 依赖触发器结果的字段（内容与评论状态、点赞数、浏览量、好友时间）返回前执行 `ReloadAsync()` 或重查；
7. 列表接口提供确定性排序、分页及 `X-Total-Count`；
8. 对公开、受限、删除和封禁状态定义明确可见性；
9. 为成功、非法参数、未登录、越权和并发边界添加测试。

容器构建验证：

```bash
docker compose build backend-api
```

本机安装 .NET 8 SDK 时也可运行：

```bash
dotnet build backend/Backend.csproj
```

## 7. 前端开发

- API 调用集中放在 `frontend/src/api/index.js`；
- 页面不拼接后端地址，统一使用 Axios 实例；
- 前端权限展示不能替代后端授权；
- 异步操作必须处理 loading、空数据和服务端错误消息；
- 分页总量从响应头读取，并为缺失响应头提供回退；
- 上传前校验图片数量、类型和大小，释放本地预览 URL；
- 修改完成后执行生产构建。

```bash
docker compose build frontend-web
# 或在 frontend/ 中执行 npm install && npm run build
```

## 8. 测试

测试通过 HTTP 访问运行中的后端，会写入开发数据库。

```bash
# 服务已启动时运行全部测试
./scripts/test.sh

# 自动重启服务后测试
./scripts/test.sh --restart

# 指定模块或 pytest 表达式
./scripts/test.sh -- tests/test_forum.py -q
./scripts/test.sh -- -k pagination

# 只验证测试收集，不访问 API
./scripts/test.sh --collect-only -q
```

测试环境变量：`BASE_URL`（默认 `http://localhost:8080`）、`TEST_TIMEOUT`（默认 10 秒）、`UV_CACHE_DIR`。

测试约定：

- 创建资源使用唯一名称，保证可重复执行；
- 不依赖数据库为空、列表顺序或其他测试的执行结果；
- API 封装放在 `test/api/`，业务断言放在 `test/tests/`；
- 权限至少覆盖 401、403、授权成功和资源越权；
- 状态或信用调整应创建隔离数据，必要时在 `finally` 中恢复；
- 分页同时验证页大小、筛选结果、稳定顺序和总量响应头。

## 9. 脚本

```bash
# 帮助
./scripts/restart.sh --help
./scripts/test.sh --help

# 生成 BCrypt 摘要；默认交互输入，不回显密码
UV_CACHE_DIR=/tmp/tongji-forum-uv-cache \
  uv run --with bcrypt scripts/encrypt.py
```

脚本均启用严格错误处理并可从任意目录调用。不要恢复旧脚本中默认 `docker compose down -v` 的行为。

## 10. Git 与协作

- 功能分支开始前先同步目标分支，提交前检查 `git status`；
- 不覆盖或提交他人的未提交改动；
- 一个提交聚焦一个目的，提交信息说明模块和结果；
- 合并前运行相关测试、前后端构建和只读冲突检查；
- 重写已发布分支历史后，只使用 `git push --force-with-lease`，并先与协作者确认；
- 不提交 Cookie、临时清单、构建输出、缓存、密钥或测试生成文件。

## 11. 常见问题

| 问题 | 排查方式 |
| --- | --- |
| Oracle 不健康 | `docker compose logs oracle-db`，检查初始化 SQL 和数据卷状态 |
| 后端无法启动 | 检查 Oracle 健康状态、连接字符串和 `docker compose logs backend-api` |
| 前端接口失败 | 检查 `VITE_API_BASE_URL`、8080 端口和浏览器网络请求 |
| 代码未生效 | 重新构建对应镜像并启动服务 |
| 测试连接被拒绝 | 确认后端已监听 8080，或设置正确的 `BASE_URL` |
| 测试重复数据失败 | 使用唯一测试数据；必要时明确执行 `--reset-data` |
| 存储过程报 `PLS-00201` 找不到对象 | C# 侧过程名必须带双引号；确认脚本已在全新数据卷或以 `appuser` 重跑 |
| OUT 参数报 `InvalidCastException` | 用 `OracleProcedure.ReadInt32` / `ReadDecimal` / `ReadText` 拆箱，不要直接 `Convert.ToXxx` |
| uv 缓存无权限 | 设置 `UV_CACHE_DIR=/tmp/tongji-forum-uv-cache` |

接口细节优先查看 Swagger；业务实现优先查看对应 Controller、Service 和集成测试。
