# 部署、集成与验收

负责人：成员 10

## 功能范围

本模块负责项目运行环境、镜像分发、数据库初始化、测试脚本维护和全流程验收。

## 具体功能

### Docker 环境

- 保证 `docker compose up -d` 可以启动数据库、后端和前端。
- 检查 Oracle、后端 API、前端服务健康状态。
- 处理端口占用、容器启动失败和数据库初始化失败问题。
- 维护必要的启动说明。

### 镜像分发

- 在镜像拉取较慢时，导出基础镜像和项目镜像。
- 组员通过 `docker load` 导入镜像。
- 确认导入后可以直接启动项目。

### 数据库初始化

- 统一整理初始化 SQL。
- 准备演示账号、管理员账号、版主账号、仲裁员账号、审核员账号。
- 准备论坛、商品、订单、纠纷和举报的基础测试数据。
- 确保重复初始化时数据可控。

### 测试脚本

- 维护 `scripts/test.sh`。
- 保证测试环境启动、执行、清理流程稳定。
- 组织各模块测试文件，避免测试之间互相污染数据。
- 定期运行全量测试并记录失败模块。

### 验收用例

- 登录注册流程。
- 发帖评论流程。
- 论坛审核流程。
- 商品发布和下单流程。
- 钱包冻结和确认收货流程。
- 纠纷仲裁流程。
- 举报审核流程。
- 通知触达流程。

## 测试要求

- Docker Compose 一键启动成功。
- 后端健康检查成功。
- 前端页面可访问。
- 数据库初始化后基础账号存在。
- 全量测试可以运行。
- 关键验收流程测试通过。
- 镜像导入后可启动项目。

指定测试文件：`test/tests/test_acceptance.py`

## 验收标准

1. 任何组员按环境说明可以启动项目。
2. 数据库初始化后具备完整演示数据。
3. 所有模块测试可以统一执行。
4. 最终演示环境稳定可复现。
