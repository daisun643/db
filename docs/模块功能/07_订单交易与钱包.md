# 订单交易与钱包

负责人：成员 7

## 功能范围

本模块负责订单、担保交易、钱包余额、冻结金额、资金清算和订单留言板。

## 具体功能

### 下单

- 买家选择商品创建订单。
- 下单前检查登录状态、信用分、商品状态和库存。
- 买家不能购买自己的商品。
- 下单成功后商品库存扣减或锁定。
- 订单生成后进入待确认或交易中状态。

### 钱包

- 用户拥有钱包余额。
- 支持查询余额、冻结金额和交易流水。
- 下单时冻结买家资金。
- 余额不足时下单失败。
- 冻结资金不能重复使用。

### 担保交易

- 买家付款后资金进入冻结状态。
- 卖家发货或确认交易后进入待收货状态。
- 买家确认收货后资金从冻结金额划转给卖家。
- 资金清算必须保证事务一致性。

### 订单状态

- 待支付。
- 已支付或交易中。
- 待收货。
- 已完成。
- 已取消。
- 纠纷中。
- 已退款。

### 订单留言板

- 每个订单创建后生成买卖双方留言板。
- 只有买家、卖家和必要管理员可以查看。
- 交易完成或取消后留言板归档为只读。

## 测试要求

- 创建订单成功。
- 买家购买自己商品失败。
- 余额不足下单失败。
- 下单后买家冻结金额增加。
- 确认收货后卖家余额增加。
- 确认收货后买家冻结金额减少。
- 资金流水记录正确。
- 订单状态流转正确。
- 订单留言发送成功。
- 非订单相关用户不能查看留言。
- 交易结束后留言板只读。

指定测试文件：`test/tests/test_transactions.py`

## 验收标准

1. 订单和钱包金额变化保持一致。
2. 资金冻结和清算符合担保交易逻辑。
3. 订单留言权限隔离正确。
