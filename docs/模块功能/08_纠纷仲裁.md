# 纠纷仲裁

负责人：成员 8

## 功能范围

本模块负责交易纠纷工单、仲裁员分配、仲裁处理、退款拆分和信用分扣减。

## 具体功能

### 纠纷创建

- 买家或卖家可以对交易中订单发起纠纷。
- 已完成很久或无效订单不能发起纠纷。
- 一个订单同一时间只能有一个进行中的纠纷。
- 创建纠纷后订单进入纠纷中状态。

### 仲裁员分配

- 系统自动分配仲裁员。
- 分配时优先选择当前待处理工单较少的仲裁员。
- 仲裁员不能是该订单买家或卖家。
- 分配结果需要记录。

### 纠纷处理

- 仲裁员查看纠纷详情、订单信息和双方说明。
- 仲裁员可以要求补充材料。
- 仲裁员给出处理结果。
- 非分配仲裁员不能处理该纠纷。

### 退款拆分

- 仲裁结果支持全额退款、部分退款、不退款。
- 部分退款需要按比例拆分冻结资金。
- 买家退款金额和卖家到账金额之和必须等于冻结金额。
- 资金处理必须放在事务中完成。

### 信用分扣减

- 仲裁判定责任方后扣减信用分。
- 信用分变更需要记录原因。
- 仲裁结果通知买家和卖家。

## 测试要求

- 买家创建纠纷成功。
- 卖家创建纠纷成功。
- 无关用户创建纠纷失败。
- 重复创建进行中纠纷失败。
- 创建纠纷后订单状态变为纠纷中。
- 系统自动分配仲裁员。
- 非仲裁员处理纠纷失败。
- 仲裁员处理纠纷成功。
- 部分退款金额计算正确。
- 纠纷完成后订单状态正确。
- 责任方信用分扣减。
- 买卖双方收到通知。

指定测试文件：`test/tests/test_disputes.py`

## 验收标准

1. 纠纷能从创建、分配、处理到资金结算完整闭环。
2. 仲裁权限严格限制。
3. 退款金额、钱包余额和信用分变化正确。
