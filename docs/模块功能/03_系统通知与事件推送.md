# 系统通知与事件推送

负责人：成员 3

## 功能范围

本模块负责系统内事件通知，包括 @ 提及、审核结果、交易状态和系统公告。

## 具体功能

### 通知类型

- @ 提及通知。
- 评论或回复通知。
- 帖子审核通知。
- 举报处理结果通知。
- 商品下单、订单状态变化通知。
- 纠纷仲裁结果通知。
- 系统公告通知。

### 通知生成

- 其他模块发生关键事件时调用通知能力。
- 通知需要包含接收人、标题、内容、类型、关联对象和创建时间。
- 同一事件避免重复生成通知。
- 通知内容应能跳转到相关业务页面。

### 通知查询

- 当前用户查看自己的通知列表。
- 支持按已读/未读筛选。
- 支持按通知类型筛选。
- 支持分页。

### 已读管理

- 单条通知标记已读。
- 批量标记已读。
- 统计未读数量。
- 用户不能操作其他人的通知。


## 测试要求

- 创建通知成功。
- 当前用户查询通知列表成功。
- 用户不能查询其他人的通知。
- 标记单条通知已读成功。
- 批量标记已读成功。
- 未读数量统计正确。
- 论坛事件能生成通知。
- 交易事件能生成通知。
- 审核事件能生成通知。

指定测试文件：`test/tests/test_notifications.py`

## 验收标准

1. 关键业务事件能给目标用户生成通知。
2. 通知列表和未读数量正确。
3. 权限隔离正确，用户只能处理自己的通知。
