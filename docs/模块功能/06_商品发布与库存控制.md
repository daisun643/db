# 商品发布与库存控制

负责人：成员 6

## 功能范围

本模块负责闲置商品发布、商品生命周期和库存控制。

## 具体功能

### 商品发布

- 用户可以发布闲置商品。
- 商品包含标题、描述、价格、库存、图片、分类、成色等信息。
- 发布前检查登录状态和信用分。
- 低信用用户禁止发布商品。

### 商品编辑

- 卖家可以编辑自己的商品信息。
- 非卖家不能编辑商品。
- 已售出或已下架商品限制编辑。
- 商品价格和库存修改需要校验合法性。

### 商品上下架

- 卖家可以下架自己的商品。
- 下架商品不可被下单。
- 卖家可以重新上架符合条件的商品。
- 售出商品不能重新上架。

### 商品状态

- 发布：商品可浏览、可下单。
- 锁定：订单创建后暂时锁定库存。
- 售出：库存为 0 或交易完成后标记售出。
- 下架：卖家主动停止交易。

### 防超卖

- 下单时必须检查库存。
- 库存扣减和订单创建需要在同一事务中完成。
- 并发或重复下单不能导致库存小于 0。
- 支持库存不足时返回明确错误。

## 测试要求

- 发布商品成功。
- 未登录发布商品失败。
- 低信用用户发布商品失败。
- 卖家编辑商品成功。
- 非卖家编辑商品失败。
- 下架商品成功。
- 下架商品不能被下单。
- 库存不足下单失败。
- 重复下单不能超卖。
- 商品售出后状态正确。

指定测试文件：`test/tests/test_market.py`

## 验收标准

1. 商品可以完成发布、编辑、下架、售出流程。
2. 权限和信用分限制生效。
3. 库存不会因为重复下单或并发下单变为负数。
