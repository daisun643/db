# 论坛治理与检索

负责人：成员 5

## 功能范围

本模块负责论坛管理能力，包括版块、标签、帖子状态流转、热度排序、敏感词审核和复合检索。

## 具体功能

### 版块管理

- 管理员可以创建、编辑、删除论坛版块。
- 管理员可以给版块指派版主。
- 版主只能管理自己负责的版块。
- 普通用户只能查看开放版块。

### 标签推荐

- 发帖时根据标题和正文提取关键词。
- 推荐已有标签。
- 支持用户选择或补充标签。
- 标签需要统计使用次数。

### 帖子状态流转

- 帖子状态包括正常、待审核、加精、置顶、封禁、删除。
- 作者可以编辑和删除自己的正常帖子。
- 版主可以加精、置顶、封禁本版块帖子。
- 管理员可以处理所有帖子。
- 已删除帖子不能恢复为正常，除非明确提供恢复功能。

### 热度排序

- 根据点赞数、评论数、收藏数、浏览量和发布时间计算热度。
- 新帖子有时间权重。
- 老帖子热度随时间衰减。
- 支持按热度、时间排序。

### 敏感词审核

- 发帖或评论时检查敏感词。
- 命中敏感词后进入人工审核队列。
- 审核员可以通过或拒绝。
- 审核结果通知作者。

### 复合检索

- 支持关键词搜索。
- 支持按版块、标签、时间、热度组合筛选。
- 支持分页。
- 搜索结果不展示已删除或已封禁内容。

## 测试要求

- 管理员创建版块成功。
- 普通用户创建版块失败。
- 管理员指派版主成功。
- 版主管理本版块帖子成功。
- 版主管理其他版块帖子失败。
- 敏感词帖子进入审核队列。
- 审核通过后帖子可见。
- 审核拒绝后帖子不可见。
- 加精、置顶、封禁状态流转正确。
- 按标签、时间、热度搜索结果正确。

建议测试文件：`test/tests/test_forum_governance.py`

## 验收标准

1. 论坛内容可以被版主和管理员有效治理。
2. 敏感内容不会直接公开展示。
3. 用户可以通过搜索和筛选找到目标帖子。
